# 🇵🇬 PNGSA-SDSU

### Papua New Guinea Student Association — South Dakota State University

The **PNGSA-SDSU Web Platform** is the official digital platform developed for the Papua New Guinea Student Association at **South Dakota State University (SDSU)**.

The platform provides a centralized online space where PNG students can access association information, discover events and opportunities, connect with other members, participate in PNGSA activities, and interact with the organization through dedicated member and administrative portals.

---

## 🌐 About the Project

PNGSA-SDSU was developed to improve communication, student engagement, information accessibility, and digital administration for the Papua New Guinea student community at SDSU.

The system includes three major components:

- **Public Website** — Public information about PNGSA, events, leadership, resources, scholarships, and student activities.
- **Member Portal** — A secure environment for registered PNGSA members.
- **Administration Portal** — Management tools for authorized PNGSA executives and administrators.

## 🛠️ Technology Stack

The platform is primarily built using:

- **HTML5**
- **CSS3**
- **JavaScript**
- **Supabase**
- **PostgreSQL**
- **Supabase Authentication**
- **Supabase Row Level Security (RLS)**
- **Git & GitHub**
- **GitHub Pages / Web Hosting**
- **ArcGIS** for geospatial components

---

## 🗺️ GIS Integration

As part of PNGSA's digital platform, geospatial technologies are used to help visualize the geographic distribution of Papua New Guinean students.

GIS components may include:

- Interactive student maps
- Geographic visualization
- ArcGIS dashboards
- Location-based student information
- Spatial representation of the PNG student community

This demonstrates how GIS can be integrated with web technologies to support student organizations and community engagement.

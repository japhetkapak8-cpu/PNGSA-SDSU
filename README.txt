PNGSA SDSU split-page website

1. Put pngsa_logo.png in the images folder.
2. Put president.jpg in images/leadership/ if you want the existing leadership photo path to work.
3. Replace YOUR_FORM_ID in membership.html and contact.html with your Formspree form ID.
4. Run: python3 -m http.server 8080
5. Open port 8080 in GitHub Codespaces.
